# SUDUN | سُدَن — متجر الحجابات

واجهة متجر إلكتروني عربية (RTL) لعرض الحجابات واستقبال الطلبات عبر واتساب، والدفع كاش عند الاستلام.

**التقنية:** React 18 · TypeScript · Vite · React Router · lucide-react · CSS منظّم (بدون Backend في النسخة الأولى، والسلة محفوظة في localStorage).

---

## 1) الحالة الحالية

- المنتجات السبعة وأسعارها وعروضها من منشورات إنستغرام @sudun_hijab — في `src/data/products.ts`.
- واتساب `9647777795064`، إنستغرام، أجور التوصيل (كربلاء 3,000 · باقي المحافظات 5,000)، ومدة التوصيل 24 ساعة — في `src/config/site.ts`.
- عروض الكمية (`offer` لكل منتج) تُحسب تلقائياً في السلة ورسالة واتساب.
- الشعار الأصلي في `public/brand/`، وصور المنتجات في `public/images/products/`.
- ما زال ينتظر تأكيدكم: سياسة الاستبدال (`src/pages/ReturnsPage.tsx`)، القياسات، الألوان الإضافية، و`siteUrl` بعد ربط الدومين.

### صور المنتجات
1. ضعي الصور في `public/images/products/` (يفضّل WebP بعرض ~1200px وبنسبة 4:5).
2. في المنتج: `images: ['/images/products/chiffon-ivory-1.webp', '...-2.webp']`
3. صور لكل لون (اختياري): داخل اللون `images: [...]`.

بدون صور، يعرض الموقع رسماً توضيحياً للقماش بلون المنتج مع شارة «صورة توضيحية» — وتختفي تلقائياً عند إضافة صور حقيقية.
صورة الـ Hero: استبدلي `FabricArt` في `src/pages/HomePage.tsx` بوسم `<img>` (التعليق موجود في مكانه).

### أجور التوصيل
```ts
deliveryFees: { 'بغداد': 5000, 'البصرة': 7000 }
```
المحافظة غير المذكورة تظهر أجورها «تُؤكَّد مع المتجر»، ولا يُضاف لها أي رقم.

## 2) التشغيل على جهازكِ

يحتاج Node.js 18 أو أحدث.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # اختبارات حساب الأسعار ورسالة واتساب والتصفية
npm run build      # فحص TypeScript + بناء نسخة الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
```

---

## 3) النشر على الإنترنت

الموقع ثابت (Static) — ينشر مجاناً على أي من هذه:

**Netlify (الأسهل):** ارفعي المشروع إلى GitHub ← Netlify ← *Add new site* ← اختاري المستودع.
Build command: `npm run build` · Publish directory: `dist`.
ملف `public/_redirects` موجود حتى تعمل روابط الصفحات عند التحديث.

**Vercel:** *New Project* ← اختاري المستودع (يكتشف Vite تلقائياً). ملف `vercel.json` موجود لنفس الغرض.

**Cloudflare Pages:** Build `npm run build` · Output `dist`. ملف `_redirects` يعمل هناك أيضاً.

## 4) ربط دومين سدن

1. اشتري الدومين (مثلاً من Namecheap أو Cloudflare أو GoDaddy).
2. في لوحة الاستضافة: *Domains* ← *Add custom domain* ← اكتبي الدومين.
3. في لوحة الدومين، أضيفي سجلات DNS التي تعطيها الاستضافة بالضبط (عادةً `A` للدومين الرئيسي و`CNAME` لـ `www`).
4. انتظري التفعيل (من دقائق لساعات) — شهادة HTTPS تتفعّل تلقائياً.
5. حدّثي `siteUrl` في `src/config/site.ts` ورابط `og:image` في `index.html` ثم انشري من جديد.
6. (اختياري) لصورة مشاركة تظهر في واتساب وفيسبوك، أضيفي `public/og-image.jpg` بمقاس 1200×630 وغيّري المسار في `index.html` — بعض المنصات لا تعرض SVG.

## هيكل المشروع

```
src/
  config/site.ts         ← الإعدادات: الاسم، واتساب، الروابط، الإعلان، أجور التوصيل
  data/products.ts       ← المنتجات (تجريبية الآن)
  data/taxonomy.ts       ← الأنواع، الخامات، عائلات الألوان، نطاقات الأسعار، المحافظات
  data/faqs.ts           ← الأسئلة الشائعة
  lib/                   ← منطق بدون واجهة: الأسعار، الهاتف، رسالة واتساب، التصفية
  context/CartContext    ← السلة (localStorage + مزامنة بين التبويبات)
  hooks/                 ← useSeo (العنوان/الوصف/Open Graph) · useAsync (تحميل/خطأ)
  components/            ← الهيدر، الفوتر، بطاقة المنتج، الصور، عناصر الواجهة
  pages/                 ← الرئيسية، المتجر، المنتج، السلة، من نحن، تواصل، السياسات، الأسئلة، 404
  styles/global.css      ← نظام التصميم والألوان والخطوط
sandbox-tools/           ← أدوات اختبار داخلية استُخدمت أثناء التطوير؛ يمكن حذفها
```

## ملاحظات مهمة
- **لا يُسجَّل أي طلب في قاعدة بيانات.** الضغط على الزر يفتح واتساب برسالة جاهزة؛ الطلب يصل فقط بعد أن ترسله الزبونة، ويُؤكَّد من المتجر.
- لا يوجد دفع إلكتروني ولا مفاتيح API أو أسرار في الواجهة.
- مستقبلاً يمكن ربط Backend بتعديل `fetchProducts` في `src/lib/catalog.ts` فقط.

### نقاط التوقف (Breakpoints)
- أقل من 600px: موبايل — شريط تنقل سفلي، عمودين للمنتجات.
- 600–899px: تابلت — قائمة الهيدر، 3 أعمدة، شريط شراء ثابت بصفحة المنتج.
- 768px فما فوق: صفحة المنتج بعمودين.
- 900px فما فوق: قائمة الحاسوب، تصفية جانبية. 1280px فما فوق: 4 أعمدة بالمتجر.
